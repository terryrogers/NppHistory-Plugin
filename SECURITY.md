# Security policy

## Supported versions

NppHistory is currently prerelease software. Security fixes are applied to the most recent published version.

## Reporting a vulnerability

Please use the repository's private **Report a vulnerability** function under the Security tab. Do not publish note contents, credentials, private paths or exploitable details in a public issue.

Include the NppHistory version, Notepad++ version, Windows version, reproduction steps and the security impact. Sanitise all sample notes and metadata.

NppHistory stores revision history locally and does not encrypt it. Users are responsible for the access controls and encryption of the selected history location.
